# Fundamentals of Programming: Laboratory Assignments

Laboratory assignments in C++ for the course **Fundamentals of Programming** at Taras Shevchenko National University of Kyiv.

> **Work in progress.** New labs will be added to this repository as the course goes on.

## Repository structure

```
.
├── LAB. 1/
├── LAB. 2/
├── LAB. 3/
└── .gitignore
```

Each `LAB. N` folder contains the solutions for that laboratory work.

## How to build and run

The programs are written in C++ and developed in Visual Studio, but any C++ compiler will work. For example, with `g++`:

```bash
g++ "LAB. 3/Exercise 1.cpp" -o exercise1
./exercise1
```

## Notes

- Only `.cpp` source files (and task descriptions in `.md`) are stored here. Project files and build output are excluded via `.gitignore`.
- Console output of the programs is in English.
